# Source Control / Version Control  
- Hệ thốg giúp lưu trữ mọi thay đổi của source code 
- Hỗ trợ nhiều người làm việc cùng lúc  
- Check history và contribution  
- Revert các thay đổi, đưa code về các version cũ hơn, không lo mất code   

### Git  
- Toàn bộ code và history được lưu trữ trên máy user  
- Commit: mỗi lần thay đổi, thêm xóa sửa code >> lưu thành một commit, được lưu vào repo 
- Repo 
    + Remote: repo nằm trong remote, trên máy chủ khác (có thể pull về)  
    + Local: nằm trên máy mình 
- Branch: tạo nhánh khác để cách ly với source code gốc  

### Github  
- Dịch vụ lưu trữ Git Repo 
- Thêm một vài tính năng cho Git: xem source code, gửi link, xem commit history,...

### Các lệnh git cơ bản  
- git init: tạo repo trên máy 
- git clone: lấy trên mạng về 
- git pull: đồng bộ trên remote

- git push
